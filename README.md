### Hi, I'm tguillain 👋

I build small, fast software that stays out of the way: native-feeling desktop apps in **Rust + Tauri**,
a self-hosted home hub on a Raspberry Pi, and web apps with **Laravel** and **Nuxt**.

- 🎮 Working on **[Lounge](https://github.com/tguillain/Lounge)**, a controller-first game launcher for Windows
- 🏠 Running my house on **[Hestia](https://github.com/tguillain/hestia)**, a ~5 MB Rust binary instead of Home Assistant
- 🤖 Into AI-assisted development: MCP servers and Claude Code skills
- 🪶 Rule of thumb: if the installer is over 10 MB, something went wrong
